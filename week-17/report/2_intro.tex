\section*{ВВЕДЕНИЕ}
\addcontentsline{toc}{section}{ВВЕДЕНИЕ}

Современные распределенные системы часто строятся по принципу разделения ответственности между независимыми компонентами. Это позволяет эффективно масштабировать отдельные части системы, использовать наиболее подходящие технологии для каждой задачи и обеспечивать высокую отказоустойчивость.

В рамках данной работы разработана учебная распределенная система управления счетами \texttt{invoices-s13} на языке Python. Система позволяет регистрировать финансовые документы, получать информацию об их текущем статусе и суммах, а также управлять списком доступных документов через единый интерфейс. Разделение обязанностей между gRPC-сервисом бэкенда и REST-шлюзом обеспечивает гибкость API и высокую производительность внутреннего взаимодействия.
